Privacy Policy

Last updated August 25, 2026

Numax is a browser extension that helps Nuvio users save, apply, and back up their Nuvio profile configurations — addons, plugins, collections, settings, watch history, and watch progress — across multiple profiles on the same account. This page explains exactly what Numax accesses, how it's used, and what is never done with it.

What Numax accesses What it doesn't do Where data lives Permissions Third parties Changes Contact

01What Numax accesses

Nuvio session / authentication data. While you're on nuvio.tv, Numax reads your Nuvio session token from your browser's local storage and uses it to make authenticated requests directly to Nuvio's own API on your behalf. This token is what lets Numax act as you — the same way being logged into nuvio.tv already does. It's never sent anywhere except Nuvio's own API.

Nuvio profile data, including watch history and watch progress. Using that session, Numax reads and writes your profile data: addons, plugins, collections, settings, watch history, and watch progress. This is the same data you could view or change by using Nuvio directly — Numax automates copying it between your own profiles rather than collecting anything new.

Google Drive data — optional. If you choose to connect Google Drive for backup, Numax requests the drive.file scope. This scope is intentionally narrow: Numax can only see and manage files it creates itself, never any other file in your Drive. This feature is off unless you turn it on.

Extension status check. Numax periodically reads a small public JSON file hosted on GitHub to check whether the developer has flagged a critical issue that requires disabling the extension. This is a static status read only — no code is downloaded or executed, and no user data is included.

02What Numax does not do

  • Does not collect personally identifiable information — real name, address, government ID, or similar.
  • Does not access health, financial, payment, or personal communications data.
  • Does not track your location.
  • Does not monitor your browsing activity, clicks, or keystrokes on any site.
  • Does not read website content on pages other than nuvio.tv.
  • Does not operate its own servers or database — there is no backend that stores your data.
  • Does not sell, rent, or transfer your data to third parties.
  • Does not use your data for anything beyond the profile management and backup features described above.
  • Does not use your data to determine creditworthiness or for lending purposes.

03Where your data lives

Your saved templates, preferences, and session data are stored locally in your browser via Chrome's storage APIs. Nothing is transmitted to any server operated by the developer. Data only ever travels between your browser, Nuvio's own API, and — only if you opt in — your own Google Drive.

05Third parties

Numax communicates only with:

  • Nuvio (api.nuvio.tv, nuvio.tv) — your own account data, at your direction.
  • Google (googleapis.com, oauth2.googleapis.com) — only if you enable Drive backup, and only within the drive.file scope.
  • GitHub (raw.githubusercontent.com) — a public, static status file, containing no user data.

No other third party receives any data from Numax.
